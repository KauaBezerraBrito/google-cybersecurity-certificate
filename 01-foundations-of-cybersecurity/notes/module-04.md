# Module 04 - Cybersecurity Tools and Programming Languages

## SIEM Tool

An application that collects and analyzes log data, used by security professionals to identify potential breaches in an organization's systems.

## Difference Between a Playbook and a Framework

Playbook: A step-by-step guide for specific scenarios.

Framework: Helps you analyze a situation and find your own solution.

## Two Types of Playbooks

### Chain of Custody

The process of documenting the possession and control of evidence throughout an incident lifecycle.

### Protecting and Preserving Evidence

The process of properly handling fragile and volatile digital evidence.

## Network Protocol Analyzer

Also known as a packet sniffer, a network protocol analyzer captures and analyzes network traffic.

## Difference Between Encoding and Encryption

Encoding: The transformation of data into a different format so it can be shared or processed across different systems.

Encryption: The transformation of readable data into a protected format that can only be accessed by someone with the appropriate key.
