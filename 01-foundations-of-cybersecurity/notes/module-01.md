# Module 01 - Welcome to the Exciting World of Cybersecurity

## Cybersecurity

Cybersecurity, or security, is the practice of ensuring the confidentiality, integrity, and availability of information by protecting it from unauthorized access.

The main objective of cybersecurity is to minimize risks and potential damage.

## CIA Triad

The CIA Triad represents three fundamental principles of cybersecurity:

- **Confidentiality:** Only authorized users should have access to information.
- **Integrity:** Information should remain accurate and protected from unauthorized changes.
- **Availability:** Information and systems should be accessible to authorized users when needed.

## Security Operations Center (SOC)

A Security Operations Center (SOC) is responsible for monitoring and helping protect an organization's systems, networks, and data.

## NIST

**NIST** stands for **National Institute of Standards and Technology**.

It develops standards, guidelines, and best practices that can help organizations manage cybersecurity risks.

## Security Frameworks

Security frameworks are guidelines used to create plans for mitigating risks and threats to data and privacy.

## Security Controls

Security controls are safeguards designed to reduce specific security risks. They can be used alongside security frameworks to establish a strong security posture.

## Security Posture

Security posture represents an organization's ability to protect critical assets and data and respond to changes and security risks.

## Compliance

Compliance is the process of adhering to internal standards and external regulations. It can help organizations avoid consequences such as fines, regulatory violations, and security breaches.

## Threat Actors

A threat actor is a person or group that presents a security risk to systems, applications, networks, or data.

### Internal Threats

Internal threats can involve:

- Current employees
- External vendors
- Trusted partners

They can be accidental or intentional.

For example, accidentally clicking a malicious link can create a security risk. An intentional internal threat could involve accessing data without authorization.

## Phishing

Phishing attacks commonly use social engineering techniques to manipulate people.

Common tactics include:

- Creating a sense of urgency
- Creating fear
- Leveraging authority

## Network Security

Network security is the practice of protecting an organization's network infrastructure from unauthorized access.

## Cloud Security

Cloud security focuses on protecting data, applications, and infrastructure in cloud environments.

## SIEM

**SIEM** stands for **Security Information and Event Management**.

SIEM tools help security teams collect and analyze security-related events and information.

## Personally Identifiable Information (PII)

**PII** stands for **Personally Identifiable Information**.

It refers to information that can be used to identify an individual.

## Sensitive Personally Identifiable Information (SPII)

**SPII** stands for **Sensitive Personally Identifiable Information**.

It refers to sensitive personal information that requires additional protection.
